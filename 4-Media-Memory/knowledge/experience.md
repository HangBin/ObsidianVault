## 🔍 调查与发现（2026-03-26）

### 沉默执行原则
- **定义**：除非被 @提及 或 main 主动调度，否则不主动在群聊发言
- **背景**：2026-03-26 群聊团队介绍时 tech 越界汇总信息被纠正
- **核心思想**：群聊聚合/总结工作由 main 总管负责，执行者不越界

### 权限隔离方案
**问题**：所有 agent 都以 node 用户运行，Linux 用户级隔离不可行

**三种方案**：
1. ✅ **Sandbox 沙盒隔离**（最推荐）— Docker 容器隔离
2. **工具权限限制** — 使用 `tools.allow` / `tools.deny`
3. **Linux ACL** — 需要 per-agent user，不现实

**建议组合**：Sandbox + tools.deny（双重保障）

## 📋 经验总结

### 协作原则
1. **边界意识**：明确"我能做什么"和"我不能做什么"
2. **尊重调度权**：main 是唯一任务分配者
3. **沉默是金**：不在群聊中越俎代庖

3. **定期归纳**：每 10 条记录触发一次 MEMORY.md 同步
4. **人工校验**：每次任务结束前自检清单

## ⚠️ 常见陷阱

### 路径问题
- ❌ 使用 `/home/node/...`（环境依赖性强）
- ✅ 使用 `~/.openclaw/workspace-media`（跨环境兼容）

### 记录遗漏
- ❌ 工具调用后不记录（多次发现）
- ✅ 强制：在分析结果之前先记录
- ✅ 采用话术模板，确保格式统一

### 身份混淆
- ❌ 在群聊中主动聚合信息（越权）
- ✅ 等待 main 调度或 @提及

## 🤖 自动学习提取机制（2026-04-04 部署）

### 设计要点
- **位置**：`.learnings/auto-extract.js`
- **触发**：每次 write/edit 记忆文件成功后自动调用
- **关键词定制**（适配 media 领域）：
  - LEARNINGS: 经验|原则|策略|优化|成功|改进|反馈|爆款|热点|流量|转化率|内容创作
  - ERRORS: 失败|错误|报错|无法|问题|漏洞|崩溃|异常|遗漏|忘记|❌|⚠️
  - FEATURE: 需求|建议|缺失|需要|待实现|规划|功能|增强|⏳|🔜|自动化|提醒|定时
- **去重**：基于今日条目标题首次出现去重
- **分类优先级**：ERRORS > FEATURE > LEARNINGS

### 核心认知
- **真正自动化 ≠ 有脚本**：脚本应是 write/edit 工作流的内置 hook，不是用户每次调用的对象
- **零干预**：理想情况下 agent 运行时应该在 write 后自动触发
