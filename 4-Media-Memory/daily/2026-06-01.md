## 22:05 - 安装配置抖音 MCP + 解释 OpenClaw MCP 与 mcporter 区别
**触发**: 用户要求安装抖音 MCP，随后询问 mcporter 与 OpenClaw MCP 的关系
**工具**: web_search, web_fetch, exec(pipx/uvx/mcporter), edit(mcporter.json), gateway(config.schema.lookup/config.get)
**结果**: ✅ 抖音 MCP 安装配置完成 + 讲清了两套 MCP 系统的关系
**决策**: 选用 douyin-mcp-server (yzfly) 通过 uvx 运行，注册到 mcporter；OpenClaw MCP 与 mcporter 是两套独立系统

### 抖音 MCP 安装详情
- **包名**: `douyin-mcp-server` (PyPI, yzfly)
- **运行方式**: `uvx douyin-mcp-server`（stdio 模式）
- **mcporter 注册**: 已添加到 `config/mcporter.json` 的 mcpServers.douyin
- **环境变量**: `DASHSCOPE_API_KEY` 已配置（阿里云百炼，用于语音转文本）
- **可用工具**:
  - `get_douyin_download_link` — 无水印下载链接（无需 Key）
  - `parse_douyin_video_info` — 解析视频信息（无需 Key）
  - `extract_douyin_text` — 语音转文案（需要 DASHSCOPE_API_KEY）
- **注意**: 服务器 IP 可能被抖音反爬，实际使用可能需要代理

### mcporter vs OpenClaw MCP 区别
| | OpenClaw MCP | mcporter |
|---|---|---|
| 配置文件 | `openclaw.json` → `mcp.servers` | `mcporter.json` |
| 管理命令 | `openclaw mcp list/set/unset` | `mcporter config list/add` |
| 用途 | 平台级 MCP 注册 | 工作区级 MCP 代理 |
| 当前状态 | 未配置任何服务 | 已配置 exa/weibo/xiaohongshu/douyin |

**结论**: 两套系统互不干涉。mcporter 是工作区级工具，OpenClaw MCP 是平台级注册。抖音 MCP 配置在 mcporter 中，通过 `mcporter call` 调用，不影响 OpenClaw 全局 MCP。 |
