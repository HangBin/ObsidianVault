## 09:17 - 闲鱼第二个商品发布闭环研究
**触发**: 用户要求从CDP提取最新cookies，研究方案一(Playwright)和方案二(API)完成发布闭环
**工具**: CDP websocket, Playwright connect_over_cdp, React fiber 遍历, curl 上传, execjs 签名
**结果**: ✅ 两个商品全部上架！
**决策**: Playwright+CDP 组合方案成功

### 方案一：Playwright 连接 CDP 已登录浏览器（✅ 成功）
- Playwright 通过 `connect_over_cdp("http://127.0.0.1:9222")` 连接已登录浏览器
- 注入 cookies 到新 profile → 被风控拦截跳转登录页 ❌
- 连接已登录的 CDP 浏览器 → 成功到达发布页面 ✅

### 核心突破：React 上传组件状态注入
- **问题**: `file_input.set_input_files()` 设了文件但 React 不识别（和昨天CDP方式一样）
- **解决**: 通过 React fiber 树遍历找到上传组件的 `memoizedProps.onChange`
  1. 浏览器 fetch 上传图片到闲鱼接口 → fileId=1252308764062160188
  2. 从 #ice-container 的 `__reactContainer$fiberKey` 遍历 fiber 树
  3. 找到 `memoizedProps.fileList !== undefined && typeof memoizedProps.onChange === 'function'` 的节点
  4. 调用 `fiber.memoizedProps.onChange({fileList: [fileItem]})` → React 识别成功

### 发布 API 抓包分析（方案二）
- 抓包到真实发布请求：`mtop.idle.pc.idleitem.publish`
- 签名用 execjs 生成（MD5 直接算不行）
- 请求体包含完整的商品信息（title/desc/price/category/imageInfoDOList 等）

### 技术经验沉淀
1. **CDP 端口**: 9222=google-chrome(有界面), 9223=snap-chromium(headless)
2. **React fiber key**: React 18 用 `__reactContainer$xxx` 而非 `__reactFiber`
3. **文件上传三步**: fetch上传→拿fileId→fiber onChange注入状态
4. **ant-select 操作**: 点击 `.ant-select-selector` 打开下拉，点击 `.ant-select-item` 选项
5. **Playwright connect_over_cdp**: 可以连接已登录的浏览器实例，不需要重新登录
