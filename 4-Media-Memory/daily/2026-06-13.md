## 14:30 - 闲鱼自动化 CDP 方案 - Chrome 启动问题排查
**触发**: 用户要求优化 xianyu_start.sh 脚本，解决 CDP 端口不通问题
**工具**: exec, write, edit, process, strace
**结果**: ✅ 找到根本原因并修复
**决策**: 用 xvfb-run 启动 Chrome，自动设置 DISPLAY 环境变量

### 排查过程
1. `sudo bash xianyu_start.sh` → `DISPLAY` 在 sudo 环境下为空 → Chrome 找不到 X Server → CDP 端口不通
2. `sudo -u bill` → DISPLAY 也是空的
3. `su - bill` → Chrome 能启动但 CDP 端口不通（`--remote-allow-origins` 格式问题）
4. **最终方案**: `xvfb-run --auto-servernum` → 自动创建虚拟 X Server + 设置 DISPLAY → CDP 端口 9222 正常监听

### 关键发现
- `sudo` 环境下 `DISPLAY` 变量不保留
- `xvfb-run` 是解决无 X Server + CDP 端口不通的唯一可靠方案
- Chrome 启动参数 `--remote-allow-origins=http://127.0.0.1:9222` 可以正常工作
