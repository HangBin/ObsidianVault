## 13:47 - 小红书反爬机制研究

**触发**: 老板要求研究小红书反爬机制

**工具**: tavily_search、tavily_extract、xhs-cli 源码分析、Spider_XHS GitHub 项目、dev.to 文章

**核心发现**:

### 小红书反爬五层防线

| 层级 | 机制 | 说明 |
|------|------|------|
| 1️⃣ TLS 指纹检测 | JA3/JA4 | 识别 Python requests 的默认 TLS 指纹，curl_cffi 可绕过 |
| 2️⃣ 请求签名 | x-s / x-t / x-s-common | 核心防线，签名算法约每月更新 |
| 3️⃣ IP 级限流 | 住宅IP封禁 | 数据中心 IP 直接拦截，需住宅代理 |
| 4️⃣ SPA 动态渲染 | 部分接口 | 需浏览器环境执行 JS |
| 5️⃣ 登录墙 | xsec_token | 部分功能需登录态 |

### 签名算法核心（xhshow 库实现）

x-s 签名流程:
1. 构建 content_string: METHOD + URI + params/payload
2. 生成 d_value（加密变换）
3. 构建 payload_array（d_value, a1, xsec_appid, content_string, timestamp）
4. XOR 变换 → base64 编码 → x3 签名
5. 组装: XYS_PREFIX + base64(json({x0, x1, x2, x3, x4}))

**需要的 Cookie 字段**: a1（用户唯一标识）+ web_session（会话ID）

**请求头**: x-s（主签名）+ x-t（时间戳）+ x-s-common（公共签名）+ x-b3-traceid + x-xray-traceid

### xhs-cli 绕过策略（关键参考）

- 搜索 API: 调用 /api/sns/web/v1/search/notes，需要 x-s 签名（xhshow 库生成）
- 读取笔记: 直接请求 xiaohongshu.com/explore/{note_id} HTML 页面，完全绕过签名
- xsec_token: 分享链接中自带的 token

### 签名算法变化频率
- 约每月更新一次，每次更新后旧签名失效（约 406 错误）
- Spider_XHS 项目持续跟踪更新（最新: 2026-04-28）

### 实战建议
1. TLS 层: 使用 curl_cffi 伪装 Chrome 120 TLS 指纹
2. 签名层: 使用 xhshow 库（pip install xhshow）
3. IP 层: 住宅代理，每 IP 10-20 请求/分钟
4. 读取笔记: 走 HTML 解析绕过 API 签名
5. 搜索 API: 需要完整签名，注意 search_id 和 x-rap-param（JSVMP 生成）
