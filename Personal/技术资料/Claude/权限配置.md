
## 1. 项目级权限配置permissions

默认情况下，针对改文件、执行命令、安装依赖等关键操作，它都会自动暂停并向你确认，只有你授权通过，它才会继续执行。
`.claude/settings.local.json` 项目级权限配置
```bash
{
  "permissions": {
    "allow": [
      "Read(*)",
      "Write(*)",
      "Edit(*)",
      "Bash(pnpm *)",
      "Bash(node *)",
      "Bash(npx *)"
    ]
  }
}
```
> 这个配置的作用就一句话，提前告诉 Claude哪些操作你可以直接做
