#### 工作区权限隔离方案

防止 agent 越界访问

方案一：启用 Sandbox 沙盒（最安全）✅
在 openclaw.json 中为每个 agent 配置独立的容器环境：
```bash
{
  "agents": {
    "list": [
      {
        "id": "tech",
        "workspace": "/home/node/.openclaw/workspace-tech",
        "sandbox": {
          "mode": "all",        // 始终沙盒化
          "scope": "agent",     // 每个 agent 独立容器
          "docker": {
            "image": "node:24-slim",
            "setupCommand": "apt-get update && apt-get install -y git curl"
          }
        }
      },
      {
        "id": "media",
        "workspace": "/home/node/.openclaw/workspace-media",
        "sandbox": {
          "mode": "all",
          "scope": "agent"
        }
      }
    ]
  }
}
```
效果：
- 📦 每个 agent 在独立 Docker 容器中运行
- 🚫 只能访问自己的 mounted workspace（容器内路径映射）
- 🔐 即使尝试 exec 绝对路径，也仅限于容器文件系统

方案二：工具权限限制 · tools.deny（轻量级）
```bash
{
  "agents": {
    "list": [
      {
        "id": "media",
        "workspace": "/home/node/.openclaw/workspace-media",
        "tools": {
          "allow": ["exec", "write", "sessions_send"],  // 只允许必要工具
          "deny": ["read"]  // ❌ 禁止读取文件（包括 tech 工作区）
        }
      }
    ]
  }
}
```
⚠️ 注意：deny: ["read"] 会完全禁用文件读取，包括自己的 workspace。适合不需要读文件的纯内容创作 agent。
