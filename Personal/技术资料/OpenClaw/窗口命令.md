会话控制、切模型、调思考级别、开调试信息

会话控制
```
/stop 中止当前任务,AI立即停止执行
/status 显示模型、提供商、会话信息 验证哪个模型处于活动状态
/compact 压缩上下文,清理历史对话,节省Token
/new或/reset 新建会话,开始全新对话
/new <model> 开启新会话并切换模型
/restart 重启

/usage off 关闭usage显示
/usage token 每条回复后显示token用量
/usage full 完整的usage
/usage cost 打印本地session的成本汇总

/agents 查看可用Agent
/skills 查看已安装技能

/context list 在做配置的改动之前，建议在 OpenClaw 会话中运行
/context detail  特定文件注入的深度分析, 怀疑文件被截断或缺失时
```

切模型
```
/model list #列出当前可用模型
/model status # 当前模型状态
/model <name> # 切换模型
```

调思考级别
```
/think off # 关闭思考
/think minimal # 最小思考
/think low # 低
/think medium # 中等
/think high # 高
/think xhigh # 极高

/reasoning 在会话中动态开启测试
```

开调试模式
```
/verbose on/off/full # 详细信息(调试用,正常建议关)
/reasoning on/off/stream # 输出推理过程
/elevated on/off/ask/full # 提升执行权限
/exec host=<...> # 执行环境参数
/quene # 队列控制
```

查看和管理当前对话里派出去的子助手
```
/subagents list # 当前有哪些子Agent
/subagents spawn # 启动一个子Agent
/subagents info<id> # 子Agent详情
/subagents log<id> # 查看某个子Agent的日志
/subagents send <id> # 给子Agent发消息
/subagents steer <id> # 中途调整方向
/subagents kill <id> # 终止子Agent
```
