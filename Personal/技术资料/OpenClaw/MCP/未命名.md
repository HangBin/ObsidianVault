MCP=万能插头
Model Context Protocol

怎么找：
1. 官方列表 modelcontextprotocol.io/servers
	小红书、GitHub、数据库等
2. 社区分享 Discord / Reddit 搜索"MCP server
3. 自己写 MCP 官方文档 参考示例代码


怎么装：
编辑配置文件: `openclaw confg edit`
```bash
"mcp": {
	"xiaohongshu": {
		"command" : "uvx",
		"args":["xiaohongshu-mcp"]
	}
}
```
保存后自动生效!也可以直接告诉龙虾"帮我配置小红书 MCP'
