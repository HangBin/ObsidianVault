**启用梦境（Dreaming）功能**

可以通过配置文件、聊天命令或WebUI界面三种方式实现。以下是具体步骤和说明：

1.通过配置文件启用

```bash
"plugins": {
		"entries": {
			"memory-core": {
				"config": {
					"dreaming": {
						"enabled": true,
						"frequency": "0 3 * * *"  // 默认每天凌晨3点运行，可根据需要调整
					}
				}
			}
		}
	}
```

2.通过聊天命令启用

```
在聊天框中输入
/dreaming status
/dreaming on
，然后按回车键执行命令。
系统会返回确认信息，表示梦境功能已成功启用。
```
