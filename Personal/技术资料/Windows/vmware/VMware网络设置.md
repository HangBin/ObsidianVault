虚拟机网络编辑器

```
1.设置VMnet0桥接VMnet信息
  设置桥接网卡为本地主机网卡
2.设置VMnet1NAT类型
  子网IP：192.168.142.0
  子网掩码：255.255.255.0
  DHCH：起始IP：192.168.142.128
        结束IP：192.168.142.254
```

设置本地VMware Virtual Ethernet Adapter for VMnet1网卡属性

```
#手动设置IP
IP地址：192.168.142.1
子网掩码：255.255.255.0
默认网关：192.168.142.28
DNS:8.8.8.8,144.144.144.144
```
