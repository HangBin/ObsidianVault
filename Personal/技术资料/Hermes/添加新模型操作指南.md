
根据您的版本（v0.11.0），有 **3 种方式** 可以添加新模型，推荐程度从高到低：

---
## ⭐ 方式一：交互式向导（最简单，推荐新手）
```bash
hermes setup
```
操作流程：
1. 选择 **Quick setup**
2. 选择 **Custom Model**（自定义模型）    
3. 依次填写：    
    - **Model Provider**：自定义名称（如 `MyDeepSeek`）        
    - **Base URL**：模型 API 地址（如 `https://api.deepseek.com/v1`）        
    - **API Key**：您的 API 密钥        
    - **Default Model**：默认模型名（如 `deepseek-chat`）        
4. 完成后提示 `Setup completed successfully` ✅    

## ⭐ 方式二：CLI 交互式添加（推荐，10秒搞定）

```bash
hermes model
```
操作流程：
1. 选择 **More providers...**    
2. 选择 **Custom endpoint (enter URL manually)**    
3. 输入 Base URL，例如：    
    https://api.deepseek.com/v1  
    https://dashscope.aliyuncs.com/compatible-mode/v1  
    https://taotoken.net/api/v1    
4. 输入 **API Key**（输入时不回显，正常粘贴即可）    
5. 从返回列表中**选择模型**（如 `deepseek-chat`、`qwen-max`）    
6. 回车确认，完成！✅    

## 🔧 方式三：手动修改配置文件（进阶用户）

### 第1步：编辑环境变量文件
```bash
nano ~/.hermes/.env
```
添加以下内容（以 DeepSeek 为例）：
```bash
bashOPENAI_API_KEY=sk-你的deepseek密钥  
OPENAI_API_BASE_URL=https://api.deepseek.com/v1
```
> ⚠️ **变量名必须是 `OPENAI_API_KEY`**，不能自定义！

### 第2步：编辑主配置文件
```bash
nano ~/.hermes/config.yaml
```
找到 `model:` 部分，修改为：
```bash
yamlmodel:  
  default: deepseek-chat          # 默认模型名称  
  provider: custom                 # ⚠️ 必须是 custom  
​  
providers:  
  custom:  
    base_url: "https://api.deepseek.com/v1"   # ⚠️ 必须包含 /v1  
    api_key: "${OPENAI_API_KEY}"
```
### 第3步：重启生效
```bash
hermes restart
```
