

**直接在 Dashboard 页面上操作**。

大梦，Dashboard 的 Chat 需要先有一个已存在的会话才能连接。操作步骤：

### 方法1：通过 CLI 创建会话（推荐）

在终端里执行：
```bash
cd /home/hermes-agent  
source venv/bin/activate  
hermes chat 
```
输入一条消息（比如"你好"），然后按 `Ctrl+C` 退出。这样就在 `~/.hermes/sessions/` 里创建了一个会话记录。

然后去 Dashboard 的 **Sessions 页面**（左侧菜单），找到刚创建的会话，点击右边的 **▶️ Play 按钮**，就会跳转到 Chat 页面开始对话。

### 方法2：直接在 Chat 页面输入

如果你已经在 Chat 页面了，直接在终端里输入消息按回车就行——PTY 会自动 spawn `hermes --tui`，但需要先有一个 session token。

**建议**：先在终端跑一下 `hermes chat` 创建初始会话，然后刷新 Dashboard 的 Sessions 页面，就能看到会话列表了。要我帮你在后台创建一个吗？
