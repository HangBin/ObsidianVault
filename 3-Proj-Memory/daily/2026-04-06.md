### 截图转链接技巧（重点）

**问题**: 截图画保存到本地（如 `/tmp/verify.png`），用户无法直接点击查看。需要将截图转为可通过 HTTP 访问的链接。

#### 方案一：Python 快速 HTTP 服务器（推荐）

```bash
# 1. 启动 HTTP 服务器（在截图所在目录）
cd /tmp
python3 -m http.server 8000 --bind 0.0.0.0 &

# 2. 获取本机 IP 地址
IP=$(hostname -I | awk '{print $1}')

# 3. 生成可访问链接
echo "http://$IP:8000/verify.png"
```

**用户访问**: 将生成的链接发送，在浏览器打开即可查看截图。

**停止服务器**:
```bash
pkill -f "python3 -m http.server 8000"
```

#### 方案二：集成到任务脚本

```bash
#!/bin/bash
BROWSER_DIR="/root/.openclaw/share/browser"
cd "$BROWSER_DIR"

# 截图
./browser-stable.sh screenshot "/tmp/verify.png"

# 启动 HTTP 服务（后台）
cd /tmp
python3 -m http.server 8000 --bind 0.0.0.0 > /dev/null 2>&1 &
SERVER_PID=$!

# 等待服务就绪
sleep 1

# 获取 IP 并生成链接
IP=$(hostname -I | awk '{print $1}')
URL="http://$IP:8000/verify.png"

# 输出给用户
echo "截图已生成，访问地址：$URL"
```

#### 方案三：生产环境建议
- **Web 服务器**: 配置 nginx/Apache 静态文件服务
- **云存储**: 上传到对象存储（MinIO、阿里云 OSS），返回签名 URL
- **OpenClaw 集成**: 使用文件分享插件直接上传

### 安全注意事项
- ✅ 服务器绑定 `0.0.0.0` 仅用于内网，确保防火墙限制外部访问
- ✅ 使用临时端口（8000-9000），用完即停
- ✅ 截图文件不宜包含敏感信息（登录状态、个人信息）
- ❌ 不要在生产服务器长期运行无认证的 HTTP 服务

### 技术要点总结

- 服务端口: 9223 (CDP)
- 截图转链接核心: 本地 HTTP 服务 + 内网 IP 访问
