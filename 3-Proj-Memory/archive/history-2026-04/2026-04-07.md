### Agent-browser 操作模板
```bash
export CHROME_PATH=/snap/bin/chromium
export AGENT_BROWSER_ARGS="--no-sandbox --disable-setuid-sandbox"

# 打开页面
agent-browser --cdp 9223 open "URL"

agent-browser --cdp 9223 click @ref_id

# 提取链接（最可靠）
agent-browser --cdp 9223 eval "Array.from(document.querySelectorAll('a')).find(a => a.textContent.includes('文件名')).href"

# 截图
agent-browser --cdp 9223 screenshot /path/file.png
```

### 临时 HTTP 服务器（规范版）
```bash
IP=$(ip addr show | grep "inet 192.168" | head -1 | awk '{print $2}' | cut -d/ -f1)
cd /tmp && nohup python3 -m http.server 9000 --bind $IP >/dev/null 2>&1 &
sleep 1 && curl -s -o /dev/null -w "%{http_code}" http://$IP:9000/filename.png
# 必须返回 200
```
