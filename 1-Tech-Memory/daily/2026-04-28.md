## 10:27 - 192.168.1.210:18789 访问问题诊断

### 现象
- http://192.168.1.210:18789/ 打不开
- http://127.0.0.1:18789/ 能打开
- 昨天也出现这问题，等了很久才恢复

### 诊断结果

| 检查项 | 状态 | 说明 |
|--------|------|------|
| 端口监听 | ✅ | 0.0.0.0:18789 正常 |
| 防火墙 | ✅ | 无拦截规则 |
| 本地curl测试 | ✅ | HTTP 200 正常 |
| DNS解析 | ⚠️ | wm210 有 IPv6 AAAA 记录 |

### 可能原因

1. **IPv6/IPv4 混合问题**
   - hostname -f 返回多个 IPv6 地址
   - 浏览器优先尝试 IPv6 连接失败，等待超时后才降级到 IPv4
   - 这解释了"等了很久"才恢复的现象

2. **Gateway 重启时间**
   - 当前 gateway 进程启动于 09:20 (约1小时前)
   - 昨天问题可能是 gateway 重启后的连接初始化慢

### 建议

1. 临时方案：始终使用 http://127.0.0.1:18789/
2. 长期方案：配置 DNS/hosts 使 192.168.1.210 只走 IPv4

### 验证
- curl 测试 192.168.1.210:18789 → 200 OK (毫秒级)
- 问题可能已随 gateway 重启自动恢复
