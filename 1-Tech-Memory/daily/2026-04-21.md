### 2. QMD向量搜索问题诊断

#### 问题症状
- `qmd vsearch` 和 `qmd query` 卡在 "Gathering information..."
- 超时（5分钟、15分钟、30分钟都无法完成）

#### 根本原因
**VMware虚拟机无法支持qmd向量搜索**

详细分析：
1. **qmd vsearch需要3个模型**：
   - embeddinggemma-300M：生成查询向量（已缓存，快）
   - qmd-query-expansion-1.7B：查询扩展（"Gathering information"就是它）
   - Qwen3-Reranker-0.6B：重排序

2. **"Gathering information..."的真正含义**：
   - 正在加载1.7B参数的大模型
   - 在CPU上加载+运行需要5-15分钟
   - VMware虚拟机没有真实GPU，只有llvmpipe（CPU模拟）

3. **Vulkan状态**：
   - Vulkan已安装，但检测到的是llvmpipe（CPU软件渲染）
   - glslc编译器版本不兼容：报错 "-f: expected hlsl_functionality1"
   - 无法编译Vulkan着色器

#### 结论
| 功能 | 状态 | 原因 |
|------|------|------|
| qmd search | ✅ 正常（毫秒级） | 只用BM25全文搜索，无需LLM |
| qmd embed | ✅ 正常 | embedding模型已缓存 |
| qmd vsearch | ❌ 不能用 | CPU太慢，编译超时 |
| qmd query | ❌ 不能用 | 同上 |

### 3. QMD命令功能说明

| 命令 | 速度 | 说明 |
|------|------|------|
| qmd search | 毫秒级 | 全文BM25关键词搜索，无需LLM |
| qmd vsearch | 几分钟+ | 纯向量相似度搜索 |
| qmd query | 几分钟+ | 混合搜索（查询扩展+向量搜索+重排序） |
| qmd embed | 快 | 生成/刷新向量嵌入 |

#### 优化选项
- `--no-rerank`：跳过LLM重排序，稍微快一点
- `-n 3`：限制结果数量
