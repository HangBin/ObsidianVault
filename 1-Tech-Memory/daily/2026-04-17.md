## 🔄 补充：QMD Collection 操作 (13:34 前后)

### 操作步骤
1. `qmd collection add --path ~/.openclaw/workspace/ --name main` → ✅ 成功
2. `qmd collection add --path ~/.openclaw/workspace/memory/ --name main` → ❌ 失败

### 错误信息
```
Collection 'main' already exists.
```

### 原因
重复使用相同的 collection 名称 `main`，导致冲突

### 正确做法
应该使用不同的名称，例如：
- `main-workspace`
- `main-memory`
- 或分开：`workspace` 和 `memory` 两个 collection
