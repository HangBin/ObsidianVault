# 记忆自动写入规范

## 概述

本文档定义 tech agent 的记忆自动写入规则，确保每次对话都能完整、及时地写入记忆系统。

**关键词**: #记忆 #自动写入 #规范 #对话结束协议

---

## 规则清单

### 规则 1：标准 frontmatter 格式

创建 `memory/YYYY-MM-DD.md` 时必须包含：

```yaml
---
created: YYYY-MM-DD
modified: YYYY-MM-DD
tags: [daily-log, tech-agent]
---
```

### 规则 2：daily-index.md 同步

如果本次操作涉及 daily/ 目录的文件变动（新增/修改/删除日志文件），必须同步更新 `/home/obsidian_vault/1-Tech-Memory/daily/daily-index.md`。

更新方式：读取当日日志文件的 `## 标题` 行，提取主题和标签，维护索引。

### 规则 3：昨天文件清理

- 扫描范围是"除当天之外的所有文件"
- **昨天也在检查范围内**
- 昨天文件只要 Obsidian 已同步完整，一律删除工作区副本
- 教训（2026-05-16）：因排除昨天不检查，导致冗余副本保留一天

### 规则 4：防跳过铁律

- 无论对话内容是什么、调用了多少工具
- 在发出任何面向用户的回复之前，必须逐字过一遍写入步骤
- 绝对不允许"我刚才已经做了"的心理跳过
- 每一步都必须有明确的执行证据（工具调用记录）

### 规则 5：每次对话必须追加记录

- 不是"有重要内容才写"，而是每次对话都必须追加
- 空对话可简写一行：`## HH:MM - 闲聊，无重要操作`

## 量化指标

| 指标 | 优化前 | 优化后 |
|------|--------|--------|
| 写入覆盖率 | ~30% | ~95%+ |
| 写入延迟 | 无标准 | < 1分钟（对话结束即写） |
