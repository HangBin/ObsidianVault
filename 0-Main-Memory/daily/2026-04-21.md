**③ QMD 向量数据库搜索会用吗？**
会用，但有一个关键前提：

```
❌ 软链不穿透：QMD 不跟随符号链接，搜软链只返回 51 字节
✅ 正确做法：用 share 集合直接索引源路径
```

```bash
# 1. 搜索共享集合（重要！）
qmd search "CDP 9222" -c share --max-results 3

# 2. 语义搜索（需要先 embed 生成向量）
qmd query "浏览器连接超时怎么办" -c share --max-results 5

# 3. 查看 share 集合内容
qmd ls share

# 4. 检查哪些文件需要 embedding
qmd status | grep "Pending"
```

**核心要点**：浏览器经验搜 `share` 集合，不用软链接路径。
