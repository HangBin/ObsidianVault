### 2️⃣ 浏览器经验 QMD 索引（软链接不穿透的正确解法）

**场景**：多 agent 共享的浏览器经验文档

**❌ 错误做法**：
- 用软链接方式：`~/.openclaw/workspace-*/memory/experience-browser-shared.md → 共享文件`
- QMD 不跟随符号链接，只索引 symlink 文件本身（51字节）
- 结果：qmd ls 显示软链接存在，但内容搜不到

**✅ 正确做法**：
- 直接索引共享目录源路径
- 用独立集合（如 `share`）直接指向 `/root/.openclaw/share/**/*.md`
- 所有 agent 通过 `-c share` 参数搜索

**配置示例**（~/.config/qmd/index.yml）：
```yaml
share:
  path: /root/.openclaw/share
  pattern: "**/*.md"
  context: "多代理共享文档集合"
```

---

### 3️⃣ QMD 检索浏览器经验标准流程

**标准流程**：
1. **检查浏览器 CDP 端口**：`netstat -tlnp | grep 9222`
2. **连接浏览器**：`agent-browser --cdp 9222 [command]`
3. **搜索浏览器经验**：
   - `qmd search "CDP 9222" -c share --max-results 3`
   - 或直接查看：`cat /root/.openclaw/share/browser/experience-browser.md`
4. **更新经验**：`echo "[新经验]" >> /root/.openclaw/share/browser/experience-browser.md`
