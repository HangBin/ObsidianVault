### 经验教训
1. **发信只需 SMTP**，IMAP/POP3 仅用于收信，不要混淆
2. **收件人角色要分离**：to（主送）/cc（抄送）/bcc（密送），不能混在一起
3. **emoji 在邮件客户端显示为 ???**，需要全部替换为文字标签
4. **PDF 无法直接嵌入邮件正文**，只能作为附件；邮件正文用 HTML 格式
5. **cron 脚本中的命令是给 AI 执行的**，不是 shell 直接执行，格式要清晰
6. **npm 网络可能不可用**，优先用 Python 标准库实现
